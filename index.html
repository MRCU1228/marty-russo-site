Marty Russo's Projects

Software

DS_OrderBook — A limit order book and price–time matching engine in C++ that attributes every operation to the data structure that makes it fast and renders the book live. Complete and tested (invariant, soak, and latency suites passing; ~7M operations per second); it now lives in its own public repository.

portfolio_mc — A C++17 Monte Carlo engine for portfolio risk: Value-at-Risk three ways, component-VaR attribution, drawdown distributions, stress scenarios, and a convergence study. Complete, with ~4,400 test assertions passing; also now in its own repository.

Trade Journal — A local-first Tauri desktop app for logging and reviewing day trades, with correct futures contract-multiplier math and a dashboard of equity curve, R multiples, and breakdowns. Version 0.1: the core is built, passes all headless checks, and builds to a Windows installer; verifying the database layer end-to-end against the running app is the current work.

marty-russo.com — This site: a bare static page deployed to GitHub Pages by a GitHub Actions workflow. Live over HTTP with the custom domain configured; the HTTPS certificate is still being issued.

RAG Backtester — A self-improving, AI-powered system for backtesting trading strategies, combining traditional financial signals with LLM-generated insights. Status: not yet started.
